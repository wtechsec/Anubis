# Anubis Command Reference

These pages provide documentation for all Anubis agent commands, with descriptions in English and Portuguese (PT-BR).

## Categories / Categorias

| Category | Commands |
|---|---|
| **File System** | `cd`, `cwd`, `ls`, `open_explorer`, `cat`, `cp`, `mv`, `rm`, `watch_dir` |
| **File Transfer** | `download`, `upload` |
| **Execution** | `shell`, `eval_code` |
| **Process** | `ps`, `ps_full`, `kill`, `list_dlls` |
| **Offensive (Windows)** | `shinject`, `load_dll`, `dump_lsass` |
| **Reconnaissance** | `env`, `pip_freeze`, `list_modules` |
| **Capture** | `screenshot2` |
| **Tunneling** | `socks` |
| **Agent Management** | `sleep`, `jobs`, `jobkill`, `exit`, `load`, `unload`, `load_module`, `unload_module`, `load_script` |
| **macOS Only** | `screenshot`, `clipboard`, `list_apps`, `list_tcc`, `spawn_jxa`, `vscode_list_recent`, `vscode_open_edits`, `vscode_watch_edits` |
